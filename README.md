# 看山出门

知乎黑客松 S3 · 赛道二「AI × 陪伴与交互（社区 × 数字伙伴）」

**一只刘看山自己过日子。你在旁边看着，它偶尔问你要不要一起；路上认识别的狗，带回来东西，和一份等你回应的邀请。**

开篇四个字：**治愈、低压力**。这四个字决定了后面所有的取舍。

---

## 核心闭环：邀请与回音

整个产品唯一必须成立的循环：

> 它出门 → 带回来发现 → 它发出一个具体邀请 → 你回应 → 你的回应成为它下一次出门的材料

三条立场：

1. **不回应不惩罚。** 没有红点、没有连续天数、没有进度条、不催。邀请会安静地留着。
2. **回应了关系会长。** 你给的东西会真的进到它下次的旅途里，能被看出来。
3. **「明天还回来」靠的是「世界在等你回话」，不是靠打卡。**

## P0 十条

| # | 做什么 |
| --- | --- |
| 1 | 领养：起名、初始喜好、性格标签 |
| 2 | 心愿：告诉它最近想看什么，可撤销 |
| 3 | 自主出行：不用指令它也会出门 |
| 4 | 沿途发现：一次带回 3–5 条，至少一条知乎内容带可点原文 |
| 5 | 归来分享：它用一句话讲今天的经历 |
| 6 | 邀请与回音：它发具体邀请，你能回应，回应进下次材料 |
| 7 | 结识与交换：路上遇到另一只狗，交换发现与近况 |
| 8 | 延后礼物：朋友捎来的东西过一段时间才到 |
| 9 | 捎话：写话让狗带给对方的主人，对方在来信里看到并可回 |
| 10 | 手账回看：能翻回去看旅途和关系 |

详细规则见 `team/` 里最新日期的交付物，索引在 [`team/STATUS.md`](team/STATUS.md)。

## 五条不变量

**违反了就不是这个产品。** 任何人拿检测问句对自己的模块，30 秒能自检。

| # | 不变量 | 检测问句 |
| --- | --- | --- |
| 一 | 狗是主体，人是客人 | 界面上有没有一个按钮让人直接操作另一个人？ |
| 二 | 一切都不是即时的 | 从我的屏幕到对方的屏幕，中间有没有一段「在等」？ |
| 三 | 不回应不惩罚 | 不回应会看到红点、指标、连续天数、催促吗？ |
| 四 | 真实来源可点，假数据显形 | 这段内容不是这条请求现拿的，写清楚了吗？ |
| 五 | 一只狗一个主人，一段经历一个出处 | 有没有可能两条路写出同一个事实的两个版本？ |

### `team/` 是什么

**当日交付的存放区，也是备份。** 规则见 [`team/README.md`](team/README.md)。

- `team/日期/字母/` —— 谁在哪天交了什么。**放进去就不再改**，写错了再放一个 `-v2`。
- [`team/STATUS.md`](team/STATUS.md) —— 索引，**只有 a 改**。查「谁交了」「还差什么」看这里。

**代码不进 `team/`**，按下面的目录归属直接放进 `app/` `lib/` 那些地方。`team/` 只放「要给别人用、还没变成代码」的规则、线框、文案、素材清单。

## 提交前自检

1. **没提交密钥。** `.env` 不在提交里，代码里没有硬编码的 Access Secret
2. **没提交数据库和上传文件。** 它们已在 `.gitignore` 里，别强行 `git add -f`
3. **本地能跑起来。** 「在我电脑上能跑」都不算数，何况跑不起来
4. **假数据在界面上显形。** 用了 fixtures 的地方，界面必须写出来

这是公开仓库，**12-07 提交前会一直公开**。请勿提交 API 密钥、账号凭据、真实用户聊天记录或个人资料。
