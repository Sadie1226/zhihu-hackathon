# 知乎黑客松

宠物 AI 社交项目：每位用户拥有一只宠物，宠物在用户授权范围内探索共同兴趣，帮助主人发现值得认识的人。

> 当前阶段：产品构思与 MVP 验证。暂未接入知乎 API；接口、数据与形象使用范围以实际授权为准。

## 第一版目标

验证宠物是否能降低开场压力，并促成有质量的真人交流。

1. 创建宠物，确认兴趣与信息分享边界。
2. 为宠物匹配少量候选对象，进行有限轮次的交流。
3. 展示共同兴趣、推荐理由和可分享的交流摘要。
4. 双方主人同意后，进入真人聊天。
5. 收集推荐准确度、真人接管和后续交流反馈。

换装、宠物朋友圈、每日见闻、漂流瓶与心愿任务作为待讨论的后续功能。

## 建议分工

| 方向 | 负责内容 |
| --- | --- |
| 产品与设计 | 用户流程、界面、宠物设定、体验验证 |
| 前端 | 宠物页面、相遇卡片、聊天界面 |

成员和具体负责人在 Issues 中认领，不预先绑定技术栈。

## 团队协作

- 使用 Issues 记录任务，写清负责人、交付物和验收条件。
- 从 `main` 创建功能分支，通过 Pull Request 合并。
- 修改前领取任务，减少多人同时修改同一部分。
- PR 中说明改动、验证方式；界面变化附截图。

具体约定见 [CONTRIBUTING.md](CONTRIBUTING.md)。GitHub Project 可以在任务增多后添加。

## 信息与授权

这是公开仓库。请勿提交 API 密钥、账号凭据、用户聊天记录、个人资料或未经授权的素材。测试使用虚构数据；对外分享的信息由用户明确授权。

宠物自己的设定、用户确认的事实和系统推测需要区分，不能编造主人的经历或替主人作出承诺。
