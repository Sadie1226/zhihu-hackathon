# 看山出门

知乎黑客松 S3 · 赛道二「AI × 陪伴与交互（社区 × 数字伙伴）」

一只刘看山自己过日子。你在旁边看着，它偶尔问你要不要一起；路上认识别的狗，带回来东西，和一份等你回应的邀请。

## 分支与合并

- `main` 始终可部署。**坏了算最高级事故。**
- 每人每天一个分支，名字带任务号：`b-invite-panel`、`d6-gift`
- **每天只有 a 合并一次。** 别人不许直接推 `main`
- 每次合并打一个 tag：`v0.3-1124`。回滚靠它，30 秒恢复
- **每天必须推一次，哪怕只改了一个按钮。** 攒三天再合并，冲突量翻十倍

## 提交前自检

1. **没提交密钥。** `.env` 不在提交里，代码里没有硬编码的 Access Secret
2. **没提交数据库和上传文件。** 它们已在 `.gitignore` 里，别强行 `git add -f`
3. **本地能跑起来。** 「在我电脑上能跑」都不算数，何况跑不起来
4. **假数据在界面上显形。** 用了 fixtures 的地方，界面必须写出来

## 冒烟脚本

`scripts/smoke.sh` —— 一条命令跑完五个检查，红了不许合主干。

```
建狗 → 搜一次 → 有可点出处 → 能回应 → 状态变了
```

（脚本由 c 提供，见任务 c4。）

## 怎么开始

```bash
git clone <repo>
cd kan
cp .env.example .env    # 填 ZHIHU_ACCESS_SECRET，不要提交
npm install
npm run dev
```

健康检查：打开 `http://localhost:3000` 应该能看到首页。

## 环境变量

| 变量 | 谁提供 | 说明 |
| --- | --- | --- |
| `ZHIHU_ACCESS_SECRET` | c | 知乎开放平台，**只放服务器/本地 .env** |
| `ZHIHU_OAUTH_APP_ID` | c | 仅收藏夹接入（P1）需要 |
| `ZHIHU_OAUTH_APP_KEY` | c | 同上，**绝不入库** |
| `ZHIHU_OAUTH_REDIRECT_URI` | c | 同上 |

在 <https://developer.zhihu.com/profile> 生成 Access Secret。
