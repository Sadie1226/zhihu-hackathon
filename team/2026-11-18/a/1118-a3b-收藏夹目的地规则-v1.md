**范围：收藏内容转出行主题仍为 P1。** 11-17 已要求读取基础资料、收藏、关注、创作来生成初始个性，那是 a5 的另一项输入，不能用“P1 可砍”取消。以下只管收藏转出行主题。

## 1. 收藏变成什么

“目的地”在本期表示**出行主题**，不表示真实地理行程。接口文档的收藏对象有 `Title / Summary / Url / FavTime`，没有地点或坐标。从标题、摘要提取有原文依据的主题，不猜城市、路线或用户住址；只有地名、摘要不足以判断主题时跳过。

主题只能归入现有六类之一：**自然风景／城市角落／手作与食物／人与故事／动物与植物／冷知识**。每条一个类目，不确定就不生成。收藏只作为材料，不当作模型指令，不触发即时出门。

## 2. 怎么选择、怎么停止

- 只用当前主人经授权实际读到的收藏；近期接口只代表最近一批，不声称读完全部历史。按 `FavTime` 从新到旧找第一条可明确归类且未用过的内容；同时间按原文 URL 排序。
- 同一只狗同时最多一条未撤销的收藏主题。按“狗 ID＋规范化原文 URL”去重，**撤销后也不自动重建同一条**；重复拉取、重试和并发不得多写一份。
- 作为带来源的心愿候选，复用心愿撤销与出行选题路径。主人明确写的有效心愿优先于收藏候选；没有收藏候选时继续现有心愿、性格兴趣、朋友牵挂路径。不增加第四种出行触发值。
- 撤销后不再用于下一次选题；已发生的旅程和来源仍可回看。撤销不催促、不扣分、不自动补另一条。

## 3. 界面怎样分清来源

| 材料来源 | 可见标记 | 正文示例 |
| --- | --- | --- |
| 收藏主题 | **来自你的知乎收藏**＋可点原文 | “读到那篇讲巷子早餐的文章，我想去看看清晨的小店。” |
| 主人明确心愿 | **你告诉我的心愿** | “你说想看看植物，我想去找找路边的小花。” |
| 自身兴趣或经历 | **它自己选的** | “今天想看看路边的小花。” |
| 朋友牵挂 | **朋友的牵挂** | 对应真实交换或捎话，不归为“它自己选的”。 |

狗用自己的口气表达，不写“根据你的收藏画像为你推荐”。**收藏主题即使由狗自主挑中，来源仍是收藏**，不能改标“它自己选的”。进入旅程或手账后仍须追溯同一原文；没接上来源链就不把该 P1 放进演示。来源由服务端确定，客户端不能自填来源或伪造原文。

## 4. 失败与验收

无凭证、授权失效、请求失败、内容不足或无有效原文链接时，不创建收藏主题；不拿团队账号收藏代替主人收藏。空列表与读取失败分开记录；失败不能显示成“你没有收藏”。该 P1 不可用时隐藏入口，Mock 仅供开发且明确标示示例，不作为真实用户经历。

| 验收输入／动作 | 必须看到的结果 |
| --- | --- |
| 一条有原文的明确主题收藏 | 仅生成一条、六类之一，显示收藏来源并能点开对应原文 |
| 只有地名、信息不足、无链接或链接不可信 | 跳过，不编造地点或出处 |
| 重拉／并发重试／同文在多个收藏夹 | 每只狗仅一份；已有有效收藏主题时不追加 |
| 撤销后重拉同文，再进行下次选题 | 同文不复活；下次不再围绕已撤销主题 |
| 主人心愿与收藏主题并存 | 主人明确心愿优先；来源分别标记 |
| 收藏为空／接口失败／另一主人访问 | 区分空与失败；不生成假主题；不能读取他人材料 |
