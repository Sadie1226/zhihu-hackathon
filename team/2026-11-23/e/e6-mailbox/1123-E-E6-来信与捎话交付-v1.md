## 页面与操作

| 区域 | 呈现与操作 |
| --- | --- |
| 页首 | “来信”与“有些话，会在路上多走一会儿”；“捎句话”在分类栏之前，回小屋入口可见 |
| 邀请与回音 | 显示 B 返回的原邀请；等待、已回应、它先去看看三种语义；不替 B 改写邀请 |
| 朋友来信 | 礼物、发现、问候、主人捎话共用信件卡；到达后才能拆开 |
| 寄出的捎话 | 仅显示自己寄出的 `co_owner_message`；作者可看自己写的话；未投递始终写“尚未送达” |
| 拆信详情 | 原文、来源入口、示例标记、回应插槽；正文允许换行和长文滚动 |
| 捎句话 | 从关系读取里的未屏蔽伙伴选择收件人，显示示例伙伴提醒；提交交给 D 的正文组件 |

没有催促红点、连续天数、未回复倒计时、已读回执压力或额外主导航。

## 状态与文案

| 依据 | 展示 | 允许操作 |
| --- | --- | --- |
| 首次读取未结束 | 正在读取这一叠信… | 切分类、回小屋 |
| 请求失败 | 暂时没读到；404 明确不可访问 | 重新读取，不显示成零封 |
| 成功且确实为空 | 信箱里还安静着 | 捎句话；回小屋 |
| `deliveredAt = null` | 在路上 | 收件侧隐藏标题与正文；不能拆信、回应或写已读 |
| 已到且 `readAt = null` | 新到 | 主动拆信后 PATCH 已读 |
| 已到且已读、未回应 | 安静地留着 | 继续阅读、可选回应 |
| `repliedAt != null` 且已到 | 已回应 | 阅读；不重复展示提交入口 |
| 已读写入失败 | 内容已打开，但已读状态没保存 | 单独重试已读，不假装保存成功 |
| 关系读取失败 | 暂时读不到可捎话的伙伴 | 重读关系；来信读取独立进行 |
| 示例伙伴 | 这是一位示例伙伴，可能不会回话 | 不伪造真人回复 |
| D 正文或举报屏蔽组件缺失 | 捎话提交暂未接通 | 保留阅读，暂不开放新发送 |

没有把缓存内容包装为当前内容；本候选不做离线持久缓存。刷新失败明确报错。

## 组件和接口

- `components/e6/mailbox-view.tsx`：展示与交互；可注入读取客户端和业务正文。
- `components/e6/mailbox-page.tsx`：读取当前 shell 身份；调用 B/D 插槽。
- `components/e6/mailbox-client.ts`：同源凭据、`no-store`、可取消请求。
- `components/e6/mailbox-model.ts`：未投递内容保护、状态与原文链接校验。
- `components/e6/mailbox-preview.tsx`：独立内存夹具；每次场景切换重建，不触达真实收发接口。
- `components/e6/mailbox.module.css`：米白纸张、棕色文字；44px 操作区，窄屏换行。

| 请求 | 使用方式 |
| --- | --- |
| GET `/api/dogs/:id/invitations` | 仅显示服务端原文与状态 |
| GET `/api/dogs/:id/inbox?filter=all` | 仅按返回的投递状态显示 |
| GET `/api/exchanges?from_dog=:id` | 当前狗发件，页面过滤主人捎话 |
| GET `/api/dogs/:id/relations` | 使用 `otherDog` 白名单，排除屏蔽关系 |
| PATCH `/api/exchanges/:id/read`，`{}` | 主人实际拆开已到信件时才调用 |
| B/D 写入 | 使用既有业务组件；E 不新增 POST 发件路由 |

E 仅触发 `readAt` 的既有接口。不写 `deliveredAt`、`repliedAt`、关系事实或狗快照；不将主人的话送入生图或狗快照。

## 启动与复验

在工程根目录运行 `npm run dev -- --port 3106`。
开发预览为 `/e6-preview`，正式身份页面为 `/mailbox`。开发预览在生产环境返回 404。

本地有 Playwright 与 Chromium 时：

```bash
node scripts/e6/verify.mjs
```

默认使用 `http://127.0.0.1:3106`。可通过 `E6_BASE_URL` 改端口，`E6_PLAYWRIGHT_MODULE` 指定现有 Playwright 模块，`E6_CHROMIUM_PATH` 指定浏览器。
脚本输出至本目录 `evidence/`。脚本与页面不自动修改真实数据库或真实时间。
