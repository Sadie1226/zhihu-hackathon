## 4. 接口形状

```
GET  /api/dogs/:id/blocked-topics     → 200 { blockedTopics: string[] }
PATCH /api/dogs/:id/blocked-topics    入：{ blockedTopics: string[] }
                                      → 200 { blockedTopics: string[] }   （规范化后回显）

约束：只收 blockedTopics 一个键；session 由 cookie 提供，不在 body 传。
错误：404 NOT_FOUND（狗不属于当前 session）
      409 CONFLICT（非数组/非字符串项/空串/超长/超量/跨站/其它字段/JSON 格式错）
      503 NETWORK（下游异常）
所有响应 Cache-Control: no-store；读取不触发写入；写入整列覆盖、不追加。
规范化：trim → NFKC；按 NFKC+小写 key 去重、保留首次原文；单条 ≤24 字、一次 ≤30 条；命中口径与 C 的 blockedBy 一致。
```
