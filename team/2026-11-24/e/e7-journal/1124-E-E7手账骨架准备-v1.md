## 4. 四态（沿用 K 的字段，不新造）

| 依据 | 展示 | 允许操作 |
| --- | --- | --- |
| 首次读取中 | 正在翻这一本… | 切分类、回小屋 |
| 请求失败 | 暂时没翻到，可以重新读取 | 重新读取，不显示成空本 |
| 成功且确实为空 | 还没有记下什么 | 回小屋 |
| `deliveredAt = null` | 在路上 | 收件侧不露标题正文 |
| 已到、`readAt = null` | 新到 | 主动拆开才写已读 |
| 已到、已读、未回应 | 待回应 | 可回应 |
| `repliedAt != null` | 已回应 | 只读 |
| 无回应 | 无回应 | 只读 |

未送达内容不得进 DOM 的保护规则与 E6 一致，直接复用 `mailbox-model.ts` 的 `canOpen` / `letterTitle` / `letterState`，不复制一份。

## 6. 需要先定的三件事

1. **断网可打开怎么做。** 契约要求手账断网也能开，但 E6 明确不做离线缓存。三个选项：
   - (a) 只做本地缓存最近一次成功读取的结果（`localStorage` + 版本号 + 过期提示）；
   - (b) 依赖 Service Worker 缓存页面与数据；
   - (c) 本期不做，标注为阻断缺陷，等 A/C 给统一缓存方案。
   我倾向 (a)：范围小、可控、能明确告诉用户「这是上次翻到的」。
2. **分类顺序。** 拟为「旅途 · 来信 · 珍藏」。若 A 希望默认落在「来信」，告诉我改。
3. **珍藏的边界。** 手册第 855 行写「纪念物 ＝ 礼物（4.4），不另建表」。所以珍藏只列收到的 gift，不含路上捡的 find。确认这一条。
