### 第三步 · 看昨天改了什么（三个办法，挑一个）

**办法一 · 最快，不用 clone —— 读一个文件就够**

打开 [`team/合并记录.md`](https://github.com/Sadie1226/zhihu-hackathon/blob/main/team/合并记录.md)，
**看最上面「当前最新」那一块**。里面有一张表，按人列了「谁必须做什么 / 不做的后果」。
你的 AI 读这一个文件就够了，不用翻别的地方。

**办法二 · 想看代码差异**

```bash
git fetch --tags
git diff --stat v1-1116 origin/main          # 先看概览：哪些文件变了、增删多少行
git diff v1-1116 origin/main -- contracts/schema.sql    # 再看某个文件的具体改动
```

**用 `origin/main` 做终点，不要用 tag。** tag 是那一刻的快照，main 随时更新，这样你不用记「现在最新是 v 几」。

**办法三 · 只看自己那部分**

```bash
git log --oneline v1-1116..origin/main -- 'app/(c)/'              # 换成你的字母
git log --oneline v1-1116..origin/main -- 'team/2026-11-16/c/'
```
