  暂定渲染顺序：底图 → cloth → hat → glasses → face（顺序未定，见 §1.2）

  ▲ 后画（压在上面）
  │

  │   L3  glasses   墨镜层    round / square / sun / none           🟡 顺序未定；V1 已定遮眼规则
  │   ───────────────────────────────────────────────────────────
  │   L2  hat       帽子层    beanie / cap / straw / none           🟡 顺序未定；V2 已定露耳
  │   ───────────────────────────────────────────────────────────
  │   L1  cloth     衣服层    hoodie / jacket / sweater / raincoat  ✅ 在 face 之下
  │                           apron / scarf-coat

  │                                                                   归属未定（Q-L4）

**注意方向**：图上「越靠上＝越后画＝越压住下面的层」。这张图描述的是**暂定顺序**，不是结论。

**图上 ✅／🟡 标的是「绘制顺序」，不是「画成什么样」。** 11-17 晚已定的三条是后者：`sun` 深色不透明镜片遮眼、浅色／透明／无镜片可见眼睛（V1）；三顶帽子都露耳（V2）；`raincoat` 帽兜连体归 `cloth`、穿雨衣不再叠独立 `hat`（V3）。三条都不改变这张图的层序标注。

### 1.2 同一张图的两种候选（`face` 与 `glasses` 的先后）

```text
  候选甲：face 在 glasses 之上    候选乙：glasses 在 face 之上
  ────────────────────────        ────────────────────────
  ① face    ← 最上               ① glasses ← 最上
  ② glasses                      ② face
  ③ hat                          ③ hat
  ④ cloth                        ④ cloth
  ⑤ body                         ⑤ body
```

V1 已定「戴 `sun` 时看不见眼睛」是**预期效果**，据此看两条候选：

- **候选乙天然满足 V1**：深色镜片画在表情之上，眼睛自然被盖住；`round`／`square` 只要镜片透明，眼睛就能透出来。
- **候选甲要满足 V1，必须加条件**：`face` 在镜片之上，眼睛会浮在镜片上；除非 `face` 在眼部留一块透明窗（属「透明区域」未定项）。

所以 V1 没有替 C 做选择，只是把问题从「谁在上」变成「谁在上＋透明区怎么留」。两条路径都保留，**仍由 C 定**（Q-L3）；E2b 期间两套都要能渲，不许写死一套。

> 本节 11-17 晚修正：原文把两种候选的表现写反了（写成「甲：太阳镜压在表情上」而甲实际是 `face` 最上）。以本版为准。

## 3. 六种典型遮挡关系

每种关系只记录三件事：**可能出什么问题 / 看哪里 / 谁确认**。层序未定时只记录现象，不判对错；已由 V1–V3 定下判据的，可以直接判通过／不通过（见 §4）。

### 3.1 衣服 × 脸部（cloth × face）

| 项 | 内容 |
| --- | --- |
| 可能的问题 | 雨衣帽兜的开口压住嘴或下巴（**帽兜已确认归本层，V3**）；高领、围裙上沿压住下巴或嘴，表情只剩半张；或衣服下沿被脸盖住，领口缺一块 |
| 需要观察的位置 | 帽兜开口边缘、颈部交界线、下巴下沿、领口最高点、`face` 图的下边界 |
| 需要谁确认 | E 定帽兜开口与领高（**V3 已定归属，形状未定**）；C 定层序（`face` 已确认在 `cloth` 之上，故问题主要是「领子／帽兜要不要画到脸前面」） |

### 3.2 帽子 × 脸部（hat × face）

| 项 | 内容 |
| --- | --- |
| 可能的问题 | 帽檐压住眼睛或眉线，`happy` 与 `waiting` 变得分不清；帽子包住耳部（**违反 V2，直接判不通过**）；帽子内沿出现一条与底图不接的硬边 |
| 需要观察的位置 | 帽檐下沿与眼睛之间是否有至少 1px 空隙、**耳根与帽檐的距离（露耳是硬要求）**、耳部轮廓是否完整、额头交界 |
| 需要谁确认 | E（帽檐高度）、a（IP 识别点：短尖耳必须露出、大黑鼻与小眼睛不能被压掉）、C（让出耳部用素材留空还是遮罩） |

### 3.3 墨镜 × 脸部（glasses × face）

| 项 | 内容 |
| --- | --- |
| 可能的问题 | `sun` 看不见眼睛**已是预期（V1），不算问题**；真问题是四张脸只剩嘴的区别（Q-P3）。反过来，若 `face` 在 `glasses` 之上，眼睛会浮在镜片上，**违反 V1** |
| 需要观察的位置 | `sun`：镜片外沿、镜腿起点、嘴部与脸型可辨度；`round`／`square`：眼睛是否真的透出来、镜框是否糊住眼睛 |
| 需要谁确认 | C（层序或 `face` 眼部透明窗，Q-L3）、E（浅色／透明／无镜片三选一与眼睛画法）、a（「戴墨镜也看得出情绪」的可辨判据，Q-P3） |

### 3.4 帽子 × 墨镜（hat × glasses）

| 项 | 内容 |
| --- | --- |
| 可能的问题 | 帽檐与镜腿在头侧互相穿插；帽檐压住镜框上沿，看起来像断掉；两个半透明边缘叠出脏色。**露耳后帽檐位置上移，原来的穿插点会变，需重新看** |

### 3.5 帽子 × 衣服（hat × cloth）

| 项 | 内容 |
| --- | --- |
| 可能的问题 | **`raincoat`＋`hat` 的组合按 V3 不应再出现**，若仍出图即为不通过；其余问题是衣领太高顶到帽檐、帽子的系带与领口重叠、帽兜轮廓与衣身断开 |
| 需要观察的位置 | 后颈、领口上沿、帽檐下沿、帽兜与衣身的接缝；另查穿 `raincoat` 时 `hat` 槽是否确实不出图 |
| 需要谁确认 | E（帽兜形状与衣身接缝）、C／D（互斥在数据层归一化还是渲染层忽略） |

### 3.6 墨镜 × 衣服（glasses × cloth）

| 项 | 内容 |
| --- | --- |

### 4.1 填写规则

- **制作状态**只能填：`未做`／`草图`／`试验件`／`待验`／`通过`／`不通过`。**没做就写「未做」，不许留空或写 OK。**
