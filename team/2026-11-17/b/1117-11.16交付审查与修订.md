## 4. b3 线框修订稿（给 e5 直接用）

> 以下是把两份交付合并、按 e1 色板和 e3 流程改过的线框与状态文案。e5 取用时以 e1 色板为准；若 a 另有裁定，以裁定为准。

### 4.1 聊天面板线框（日常交流，小屋内）

```
┌─ 说说话 ───────────────────────┐   ← 标题 20px 区块字号，正文色 #293443
│                                │
│  ┌──────────┐                  │   ← 狗：左侧气泡，纸面 #FFFDF8＋细边框 #DED6C8
│  │ 它说的话  │                  │     正文 #293443；左下小圆角；不用自定义绿紫
│  └──────────┘                  │
│                 ┌──────────┐   │   ← 主人：右侧气泡，浅底 #EEF1E8＋正文 #526447
│                 │ 我说的话  │   │     右下小圆角；颜色取自 e1「植物绿浅底」
│                 └──────────┘   │
│                                │
│  （空时：它还没说过话。）        │   ← 空状态左上角灰字 #626B73；无感叹号、无催促
│                                │
├────────────────────────────────┤
│  [ 输入框，可换行……      ] [发送]│   ← 发送＝主要动作红 #98483E 白字（e1 定）
│  闲聊说完就完，不会记成任务。     │   ← 单向记忆声明，明示不落长期任务
└────────────────────────────────┘
```

**状态规则（替换原 §5）**

| 状态 | 界面 |
| --- | --- |
| 空 | 「它还没说过话。」输入框可用，无强制开场 |
| 发送中 | 消息乐观上屏（本人可见），标注「还没送到」，不宣称它已听见 |
| 已确认 | 接口返回成功后才去掉「还没送到」；不写「已送达/已记住」 |
| 结果不确定 | 超时/丢响应：保留输入与原消息，说明「这次没确认送出，可重试」，不自动重复 POST |
| 失败 | 就地说明＋重试，保留已输入文字；不自动重发 |
| 降级 | 接口未接时写明这是示例，不做真实记忆/送达的承诺 |

- 色值一律取 e1 第 2 节色板；圆角普通 3px；动画支持 `prefers-reduced-motion`，开启时去掉 pop/上浮但保留全部信息。
- `POST /api/chat` 形状未定，实现前请 c 给接口（见第 5 节）。

### 4.2 回应入口与三状态（修订文案）

**入口（按 e3 第 2、4 节，三处＋各自返回）**

| 入口 | 位置 | 关闭/返回 |
| --- | --- | --- |
| 小屋 `/home` | 归来状态句下方、聊天入口之上，独立邀请区 | 回小屋 |
| 旅途 `/trip` | 「它回来以后说的话」下方 | 回本次旅途 |
| 来信 `/mailbox` | 独立邀请区，与 exchange 列表分开 | 回来信列表，恢复位置与筛选 |
| 手账 `/journal` | 「它问过的事」邀请历史 | 回手账详情（P0 第 10 条：包括没被回应的那些邀请） |

**回应方式（补给 B 第四节硬约束）**

- 底部弹层：一句话（≤200 字）＋可选一张照片（≤5MB，jpg/png/webp）；文字或照片至少一种才能提交。
- 两个都不给也能点「先不回」——不提交、不写任何记录。
- 照片失败就地提示体积/格式上限，**已输入文字不丢**；重复提交只产生一条回应（幂等，b2 第 8 条）。

**三状态文案（修订）**

| 状态 | 界面 |
| --- | --- |
| 它在等 | 「它在等你回一句话」＋具体动作＋理由＋「回一句」/「先不回」 |
| 已回应 | 「你回应过了」＋它当时收到的那句话＋「下次出门会带上」 |
| 没回应 | 什么都不发生。不催、不计数、不显示「已逾期」，下次打开还在原地 |

- 「先不回」按钮显示「它不会催你。邀请会一直留着。」，不做任何记录。
- 把「已经跟着它出门了」改成「下次出门会带上」——回应成为材料是 b8（11-26）才做的事，现在说成已发生会踩不变量四。
