## 搭配和生图接线

| 槽位 | 可选 | 限制 |
|---|---|---|
| 头饰 head | P05、P13、P25 | 0 或 1 |
| 眼镜 eyes | P16、P22、P23 | 0 或 1 |
| 斜挎／携带 carry | P12、P15 | 0 或 1 |
| 背部 back | P19 | 0 或 1 |

- 套装模式只穿 1 套，整套图层已经包含套装自带的帽子、围巾或其他部件。切换到套装模式时，清空单品和四个配饰槽。
- 自由搭配允许不穿单品或选 1 件单品。四个配饰槽分别选 0 或 1 件。帽子加挎包可搭配，同槽第二件应替换第一件。
- 表情最多 1 个。F09 自带深色镜片效果，与眼镜槽和自带眼镜的 T07 互斥。
- 生图与预览共用同一份有效选择。套装模式传套装 ID 与可选表情。自由搭配传单品 ID、每槽最终选中的配饰 ID 与可选表情。清空或替换后以新选择生成角色描述，避免把历史选择留在提示词里。
- 从后往前绘制为背部、底身、表情、单品或套装、斜挎／携带、眼镜、头饰。切换表情使用去眼底身。实际产品接线和生成端联调待 A 确认。

## 来源与修订

压缩包编号与红勾图的款式 ID 不同。wardrobe.json 每件附实际来源，现有 ID 保留，新拆款使用 S09。

- 18 件使用三个导出包内的透明素材。T02 邮差和 T10 牛仔的帽子与衣身分别对齐。压缩包中的橙盖帽未见第三张勾选，因此不入选。
- S09 取 export (3).zip 的 S04.png，去掉旧 T04 的头饰及披肩上另挂的贝壳挎包，保留蓝色披肩、星饰和滚边。
- S03 口袋围裙采用 export (3).zip 的 S05.png，重新定位双肩带、围裙下摆及手臂间距。P15 星星包采用 export (4).zip 的 P06.png，让肩带接到画面左肩，包身落在右腰。P21 薄荷包未勾选。
- T07、S02、P12、P19、P22、P23 回查仓库交付提交 b80d66e。已存在可用的独立透明层，因此复用原图层。导出包的叶片披肩自带斜挎件，勾选图的 S02 是单独披肩，采用历史提交中的独立版本。
- 来源与保留范围取自勾选图。整体覆盖荒野、冬日、露营、街头、海边和室内休息，保留少量花冠、贝壳等轻松款式。

## 验收与复跑

review/ 内有三类选款总览和 9 套跨槽混搭示例。安装 Pillow 后执行 python render-wardrobe.py --verify 可检查 34 张逐项预览、960 种自由搭配的选择及层序，以及 7 个非法选项组合。执行 python render-wardrobe.py S04 P13 P16 P12 --output trail.png 可导出工装马甲、棒球帽、护目镜和保温壶的组合。本次混搭图与离线校验随包交付。
