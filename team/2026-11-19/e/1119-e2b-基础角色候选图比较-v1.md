## 一页结论

1. **六张图是两组，不是六个候选。** 三张「三视图」（img1 / img2 / img3）是同一个设计的侧视＋背视，**没有正面**，不能当 96×96 底图用；真正的候选是三个正面视图（img4 / img5 / img6）。

2. **三张候选都不是现成可用的像素素材。** 全部是 JPEG、无 Alpha、背景纯白；原生像素只有 14–16px，角色本体高约 58–69px。要放进 96×96 画布、对齐现有底图的 89px 身高，必须放大约 **1.3–1.5 倍**，边缘必然变软、出现灰边。

3. **三版共享三处系统性偏差**（不是某一版的个别问题）：
   - 腿长占身高 **22%**，正式底图是 **9%**（长了一倍多）；
   - 手臂是上粗下细的**楔形，没有手掌**，官方是细黑棍＋独立圆手；
   - 耳朵偏宽、V 形缺口偏浅（耳缝只到 y12，占身高 13%）。

4. **现有 21 个换装素材的锚点全部对不上。** 眼镜开口在 y28–38，候选眼睛在 y24–27（整条落在开口上方，会被上框遮住）；连帽衫下摆到 y84，候选身体下沿在 y68（下摆会垂到小腿上）。**采用任何一版，都必须重测 hat / glasses / cloth 锚点。**

5. **三版之间的差别在「阴影量」和「轮廓完整度」，不在结构。** 三版的眼睛位置、耳尖、最宽处几乎完全一致（差 ≤1px）。

## 2. 逐项检查

### 2.1 尺寸 / 格式 / 透明背景 / 像素边缘 / 角色占位

| 项目 | img4 | img5 | img6 | 正式 `body.png` |
|---|---|---|---|---|
| 格式 | JPEG | JPEG | JPEG | PNG |
| 色彩模式 | RGB | RGB | RGB | RGBA |
| Alpha 通道 | **无** | **无** | **无** | 有（真透明） |
| 背景 | 纯白 253–255 | 纯白 255 | 纯白 255 | 透明 |
| 画布 | 1280×1280 | 1280×1280 | 1280×1280 | 96×96 |
| 角色外框 | 770×1038 | 718×952 | 636×871 | 70×90 |
| 角色占画面 | 60%×81% | 56%×74% | 50%×68% | 73%×94% |
| 原生像素尺寸 | ≈15px | ≈14px | ≈15px | 1px |
| 角色原生高度 | ≈69px | ≈66px | ≈58px | 90px |
| 放大到 89px 需 | ×1.29 | ×1.35 | ×1.53 | ×1.00 |
| 边缘过渡 | 1px 灰阶过渡 | 1px 灰阶过渡 | 1px 灰阶过渡 | 硬边 |
| 显著色数 | 108 | 113 | 84 | 2 主色 |

**要点**

- **没有透明背景。** 三张都是白底 JPEG，背景亮度 253–255。要落地必须抠图，而且因为身体是白色、背景也是白色，只能靠描边和阴影判断边界。
- **三张的构图占位不同**（60%/56%/50% 宽），直接互换会导致大小不一致，必须各自归一化。
- **原生像素不够。** 台阶宽度实测 14–16px，角色本体只有 58–69px 高。落到 96 画布的 89px 身高要放大 1.3–1.5 倍 —— 这正是"看起来糊"的根因，不是 JPEG 压缩造成的。
- **边缘不是纯硬边。** 每处黑/白交界都有 1 个过渡像素（例如 255 → 181 → 80）。真像素画应该是 255 → 80 一步到位。
- 六张图左上角都带 **「AI生成」水印**（浅灰，不影响裁剪，但属于来源标识）。

**结构层面的判断**

- **头部轮廓**：三版都是「头身一体蛋形」，与官方一致；但肩部收窄比官方明显，身体更像"桶"。
- **耳朵**：三版几乎相同 —— 宽、钝、V 形缺口浅。官方耳朵是窄长带深缺口。这是共同偏差。
- **眼睛**：三版完全一致（菱形/十字形点，x=32.5 / 60.5，y=25）。形状与官方的小圆点不同，但这是像素画的常见处理。
- **鼻子**：A/B 18×17，C 20×18，都带一枚白色高光点。官方的鼻是突出圆球，三版都偏扁平。
- **四肢完整性**：三版都有两条腿、两条手臂，无缺件。但**手臂是上粗下细的楔形，没有手掌**，官方是细棍＋独立圆手 —— 这是还原度上最大的一处偏差。
- **A 的轮廓缺陷**：把剪影做洪水填充测试时，A 的身体内部被外部"灌穿"了 —— 因为右侧和部分左侧只有浅灰软边、没有黑描边（边界 27.2% 的像素亮度 >128）。这意味着 **A 无法自动抠图**，必须手工补边。B、C 的轮廓闭合，可以自动抠。

### 2.4 与现有 96×96 换装素材的画风协调

| 维度 | 正式素材（a4-v25 wardrobe） | 三个候选 | 影响 |
|---|---|---|---|
| 色温 | 暖白 `rgb(254,250,240)` + 深棕 `rgb(62,44,46)` | 纯中性灰，色度极差中位 2–3、最大 7–17 | 并排会明显偏冷 |
| 明度层次 | 两色扁平：黑描边＋暖白，中灰 **0%** | 3–4 层灰阶，中灰 18.9–32.2% | 候选更"立体"，与扁平底图不协调 |
| 描边 | 深棕、1px、通体闭合 | 纯黑 / 深灰，1px，A 有 27% 边缘缺失 | 描边颜色与完整度都不一致 |
| 像素颗粒 | 1px = 1px（原生 96） | 原生 14–16px，落 96 后 1px ≈ 1.3–1.5 屏幕像素 | 颗粒感不同，混排会看出"分辨率差" |
| 高光 | 无（纯扁平） | 鼻子上有独立白色高光点 | 多了一个正式素材里没有的语汇 |

**结论**：三张候选与现有素材**不是同一套画风**。候选是"带灰阶阴影的立体像素画"，现有素材是"两色扁平像素画"。同屏混用会一眼看出差异 —— 这不是"好或不好"，而是"要不要统一"的决定。

### 2.5 叠加衣服 / 帽子 / 眼镜的可行性

测试方式：把候选归一化到 96 网格（对齐 headTop=3 / footBaseline=92），按正式层序 `body → cloth → face → hat → glasses` 叠加 `cloth-hoodie`、`face-happy`、`hat-beanie`、`glasses-round(V1)`。

| 冲突 | 实测 | 后果 |
|---|---|---|
| 眼镜压在鼻子上 | 镜片开口 y28–38；候选眼睛 y24–27；正式 `face-happy` 眼睛 y28–31 | 双眼整体落在开口**上方**，被上框整条遮住，镜片里只剩鼻子 |
| 衣服把腿包住 | 连帽衫下摆到 y84；候选身体下沿 y68（正式底图 y82） | 下摆垂到小腿，遮住 16px 腿长，**整个人像没有腿** |
| 帽子偏窄 | 毛线帽 x34–61（28px）；候选头部 y20 处宽 44px（正式 52px） | 两侧各露 8px 头顶；帽底 y23 距眼睛 y25 仅 2px，视觉上压眉 |

**这是「现有锚点不能沿用」，不是「候选不能用」。** 只要重测 hat / glasses / cloth 三个锚点，叠加本身是可行的 —— 水平方向的眼睛位置（32.5 / 60.5）与正式素材（33 / 61）几乎完全一致，说明角色比例是同一套的。

但注意：**腿长 22% vs 9% 这一条不能靠改锚点解决**。衣服下摆是按"身体到 y82"画的，候选身体只到 y68，除非改衣服或改腿长，否则下摆一定会垂到腿上。

## 3. 三版各自的优缺点

### 候选 A（img4-front-b.jpg）

**优点**
- 中灰占比 24.3%，三版里最接近"扁平"的一档，与现有素材的风格差最小。
- 脚部有分趾结构，是三版里最接近官方"圆脚"细节的一版。
- 鼻子高光位置自然，不抢眼。
- 手臂与身体的分界最清楚（不糊在一起）。

**缺点**
- **轮廓不闭合**：右侧和部分左侧没有黑描边，边界 27.2% 的像素亮度 >128。自动抠图会漏，必须手工补边 —— 这是三版里唯一的硬技术缺陷。
- 手臂与身体之间有一道明显白色缝隙，归一化后更明显，需要修。
- 耳缝最浅，帽子最难定位。

### 候选 B（img5-front-c.jpg）

**优点**
- **轮廓最完整**：边界 76.5% 是暗描边，四边闭合，可以自动抠图，三版里最省工。
- 中灰占比 18.9%，三版里最低，与现有扁平素材最接近。
- 体侧阴影过渡最柔和，缩到 96 后不容易出现脏边。
- 脚掌圆润，接近官方。

**缺点**
- 鼻梁与鼻翼之间的灰色过渡偏软，落 96 后容易糊成一片，鼻子边界不够清楚。
- 手臂比 A 细，但同样没有手掌结构。
- 耳朵略窄，帽内径更难对。

### 候选 C（img6-front-d.jpg）

**优点**
- 轮廓对比度最高（黑 29.9%），缩到 96 后边缘最"硬"，像素感最强。
- 鼻子最大，正面辨识度最高，远看最像刘看山。
- 体侧有一整片灰阴影，立体感最强。

**缺点**
- **原生分辨率最低**：角色只有 ≈58px 高，要放大 1.53 倍才能到 89px，是三版里最糊的。
- 中灰占比 32.2%，阴影最重，与"两色扁平"的现有素材冲突最大。
- 体侧大片灰阴影与衣服叠加时，会在衣领、袖口处出现脏边（灰阴影透出来）。
- 手臂最细，与官方"细棍＋圆手"差得最远。

## 4. 如果采用某一版，必须先做的事

以下不是建议，是把"采用"变成"可用"的必要前置条件：

1. **重测 11 个锚点**（canvas / centerX / footBaseline / headTop / noseCenter / eyeLine / mouthLine / glassesBand / earLeft / earRight / hatAnchor / clothAnchor）。`manifest` 目前仍是 `BLOCKED`，本次实测已经给出了其中 8 个的候选值，可直接填。
2. **决定腿长**：22% vs 9%。改腿 = 重绘，超出本次范围；不改腿 = 衣服下摆必须重画。
3. **决定手臂**：加不加手掌结构。同样是重绘。
4. **决定色温**：候选改暖，还是正式素材改中性。二者必须选一个，否则同屏有色差。
5. **决定阴影**：候选保留灰阶（立体），还是压成两色扁平（与现有素材一致）。
6. **抠图方案**：A 需手工补边；B、C 可自动。

1. **三个正面候选里选哪一个**（或都不选，另找）。我不做推荐排序 —— 三版的差别是"阴影量 / 轮廓完整度"的取舍，属于美术判断。

4. **色温与阴影**：候选向现有素材靠（改暖、压扁平），还是现有素材向候选靠（改中性、加阴影）。
5. **是否要我把 8 个已测出的锚点值填进 `manifest` 草案**（目前仍是全 null + BLOCKED）。等你选型后再做更稳妥。
