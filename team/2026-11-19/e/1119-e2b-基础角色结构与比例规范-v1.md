## 一页结论

1. **现有 `body.png` 不能直接沿用。** 它有四个结构问题：绕自身轴 13.9% 不对称、双臂不等长（左臂 y48–72 / 右臂 y50–82）、右下多一块白色附属（x66–77, y74–83）、鼻子中心偏轴 2.5px。

2. **19 个素材没有统一中心轴。** 实测中心分布在 **43.0–47.5** 之间：body 外框 47.5 但内容轴 46.0，6 件衣服在 46.0，face 与 round 眼镜在 47.0，square/sun 在 46.5。**`hat-cap` 的 43.0 不是错位**——它的帽冠 x39–55（中心 47.0）与另两顶帽子完全一致，43.0 只是左侧帽檐把 bbox 拉偏的结果（详见适配检查表 §3.7）。真正的偏移是「衣服整套 −1.5px」加「body 内部鼻/腿/耳各自偏 1.5–3px」。

3. **规范锁「包络 + 锚点」，不锁像素。** 只要新角色落在同一套包络里（头 y14–42、躯干 y53–82、腿 y84–92、眼 33/61），18 张换装件就能继续用；耳形、眼形、手的画法可以自由重设计。

4. **正式素材本身也不是纯色板像素画。** `body.png` 的 4416 个像素分散在 17 个近似色上（`254,250,240` / `254,250,239` / `255,251,240` 应为同一色），最大一色只占 16.7%；17 件非空素材里 15 件都是 17–18 色，face ×4 更到 33–40 色。新规范要求 ≤8 色且同色完全一致。

5. **推荐方案乙：按规范重画一张 body。** 修补现有 body 的成本高于重画，且会保留上述结构问题。

## 2. 结构规范

### 2.1 硬约束（改动即破坏换装，必须遵守）

| # | 约束 | 值 | 依据 |
|---|---|---|---|
| H1 | 画布 | 96×96，原点 (0,0)，RGBA | 全局 |
| H2 | 脚底线 | y = 92 | body 最后一行 |
| H3 | 头顶 | y = 3 | body 首行（耳尖） |
| H4 | 中心轴 | x = 47.5，容差 ±1px | body bbox 与帽子 |
| H5 | 耳尖中心 | 左 (34,3)、右 (58,3) | body y=3 两段游程 |
| H6 | 耳根合并线 | y = 14 | body y13 两段、y14 单段 |
| H7 | 头部宽度 | y20 处 52（x20–71）；最大 55（x18–72）@ y24–42 | body 逐行游程 |
| H8 | 眼中心 | x = 33 / 61，眼框 y28–31（5×4） | 四张 face 并集 |
| H9 | 眼区留白 | x30–36 与 x58–64、y27–33 必须空白 | 供任意表情落位 |
| H10 | 鼻 | 17×16，y22–37；中心 x 建议 47.5（实测 45.0） | body 最大暗块 |
| H11 | 嘴区留白 | x40–53、y40–47 必须空白 | 四张 face 嘴并集 41–46 |
| H12 | 躯干 | y53–82，最宽 66（x13–78）@ y61–66 | body 逐行游程 |
| H13 | 腿 | y84–92；左 x28–40、右 x49–61；腿缝 x41–48（8px） | body 逐行游程 |
| H14 | 轮廓 | 闭合、无缺口、1px 描边、无半透明 | 抠图与叠加前提 |

### 2.2 软约束（可自由设计）

| 项 | 可动范围 | 注意 |
|---|---|---|
| 耳内造型 | 尖/圆、内侧缺口深浅 | 外缘不得超出 x22 / x68（y≤13）；耳尖仍须落在 y3 |
| 眼睛形状 | 5×4 内自由（圆点/菱形/十字） | 不得超出 H9 留白区 |
| 鼻高光 | 可加 1px 暖白高光 | 高光不得越过 y22 上沿，否则顶到帽子 |
| 手臂姿态 | 外缘不超过 x13 / x82，手不低于 y80 | 现有 body 双臂不等，重画须对称 |
| 尾巴 | 正面不可见；若露，只能在 x66–77、y74–83 | 现有 body 这块是白色无描边，像"多余附属" |
| 表情 | 由 face 层负责 | body 本身不画眼睛 |

### 2.3 画法规则

| 项 | 规范 | 现状 |
|---|---|---|
| 调色板 | **≤8 色**；同一色值必须完全相同 | `body.png` 17 色，最大一色仅占 17% |
| 主色 | 暖白 `rgb(254,250,240)` + 深棕 `rgb(62,44,46)` | 一致 |
| 阴影 | 最多 1 级中间色 | `body.png` 中灰占比 0%（纯两色） |
| Alpha | 只有 0 与 255，**禁止半透明** | 现有素材全部合规（semi=0） |
| 边缘 | 硬边，禁止抗锯齿 | 现有素材合规 |
| 描边 | 1px，深棕，闭合 | body 有缺口（右侧臂与身体间） |

### 3.3 与现有素材的对位关系

- **眼 → 眼镜**：眼中心 (33,29.5)/(61,29.5)；`glasses-round` 开口中心 (33,30)/(61,30) → **水平完全重合，垂直差 0.5px**。

- **腿 → 衣服**：腿长 9px（y84–92），占身高 10%，符合"短腿"要求。

## 6. 推荐实施方案

### 方案甲 · 修补现有 body.png

在原图上改：镜像右半边、补耳形、加手掌、清色板。

- 优点：改动最小，与旧素材同源。
- 缺点：会保留"头身比例偏瘦、耳朵钝、没有手掌"这些**辨识度**问题；且 17 色噪声要逐像素清，工作量接近重画。
- 风险：镜像会改掉现有姿态，锚点仍需全部重测。

### 方案乙 · 按本规范重画一张 body（推荐）

96×96 起稿，6 色板（暖白 / 深棕 / 2 级阴影 / 高光 / 透明），按 §2.1 硬约束落位。

- 优点：一次解决对称、比例、色板、轮廓闭合四个问题；耳朵可以按官方形态画（窄长带缺口），提升辨识度；色板干净，后续 18 件可以逐步跟上。
- 缺点：与现有 17 色的旧素材并排会有轻微色差（旧素材有 ±1 抖动，新图完全纯色）。
- 风险：见 §7。

### 方案丙 · 重画 + 同步清理 18 件色板

在乙的基础上，把 18 件换装也量化到同一 6 色板。

- 优点：全局一致，是最终该有的状态。
- 缺点：工作量最大，且会动到 18 个已验收文件，需要 C/a 同意。
- 建议：作为**独立后续任务**，不在本次范围。

**推荐乙**，并把丙列为下一阶段。

## 7. 风险

| 风险 | 影响 | 缓解 |
|---|---|---|
| 耳形改窄后，帽子两侧留白从 12px 变成 14px+ | 3 顶帽子视觉上"变小" | 保持 H7（y20 处 52）；耳只改内部造型与缺口，不改外缘 |
| 鼻子居中到 47.5 | 与 `glasses-round` 鼻梁（x40–53）错开 2px | 鼻梁本来就压在鼻子上，2px 内可接受；若不可接受，保留 45.0 并在 manifest 注明 |
| 双腿居中 | 与 5 件衣服下摆的左右余量变化 | 下摆 y84 不变，仅水平居中，影响 ≤3px |
| 新 body 纯色板 vs 旧素材 17 色噪声 | 同屏可见轻微色差 | 先接受，等方案丙统一 |
| body 一变，11 个锚点全部要重录 | manifest 需重跑 | 本规范已给出全部候选值，可直接填 |
| `cloth-raincoat` 覆盖 y3–83，下摆实际停 y80 | 下摆短 4px、y81–83 挂 3px 碎屑、x37–41 y33–37 压住鼻子、帽兜顶与 hat-beanie 重叠 165px（帽兜退化成领圈，不破图） | 建议拆成「雨衣 + 帽兜」两件；或补齐下摆到 y84、删尖刺与压鼻碎片、帽兜压到 y10 以下 |
