## 2. 编号与阅读顺序

- **衣服表**：先上排后下排，每排从左到右 → 01–10
- **帽子表**：同上 → 01–08
- **眼镜与表情**：按 `x0` 从左到右编号，同类相邻的两个视为**一副/一组**（左眼+右眼、左镜片+右镜片），不拆成单只

一副眼镜 / 一组眼睛必须是**一个文件**，不能拆成左半右半——拆了就违反「不得将不同素材合并」的反面：把同一件素材切碎。

## 4. 命名规则

```
1119-e-{类别}-{slug}-96-v1.png
```

| 段 | 取值 |
|---|---|
| 类别 | `cloth` / `hat` / `glasses` / `face`，与项目五层一致 |
| slug | 英文短名，看得懂就够；眼镜用 `形状-颜色`（`oval-thin` / `round-gold` / `sun-black`） |
| `96-v1` | 画布 96，版本 1；返工出 v2，不覆盖 |

组合表情的 slug 是**语义名**（`calm` / `happy` / …），不是部件名，因为它是成品层；具体由哪两个部件合成写在 `1119-e-新素材-清单-v1.json` 的 `composedFaces` 字段里。

## 5. 落位规则（每层不同，不是统一锚点）

| 层 | 落位方式 | 依据 |
|---|---|---|
| cloth | **按宽度**缩放到 44–61，上边贴领口线（y50–55），下边钳制不超过 y92 | 正式 cloth 内容框 x18–74 y53–84（57×32） |
| cloth（雨衣） | **按高度**缩放到 81，底边贴 y83 | 正式 `cloth-raincoat` x13–82 y3–83 |
| hat | **按高度**缩放到 16–18，底边贴 y21–23 | 正式 hat 占 y6–23，头宽 55 |
| glasses | **按宽度**缩放到 40–49，垂直中心贴眼线 y29.5–30.5 | 正式 glasses x23–71 y23–37 |
| face（眼） | **按宽度**缩放到 33，垂直中心贴 y30 | 正式 face x31–63 y28–46，眼在 y28–32 |

统一规则只有一条：**水平中心一律 47.5**（与 `body.png` 的 bbox 13–82 中心一致）。

为什么不能统一用「脚底 92」：帽子在头顶、眼镜在眼线、衣服在躯干，三者跟脚底的距离不同。全用脚底锚点会让帽子和眼镜浮到身体下方。**每层用自己的功能基准，这是「不能把所有类别都使用同一个锚点」的具体落法。**

## 6. 待确认

1. **表情只有眼睛，没有嘴。** 这是本批素材最大的结构缺口：6 个完整表情是靠借用正式 `face-happy` 的嘴拼出来的。若团队不接受「新眼 + 旧嘴」的混搭，需要补一张嘴部素材表。
2. **三套眼（晕圈 / 横线 / 方块闭眼）眼径 11–13 px，正式只有 5 px。** 按脸宽对齐会压住鼻子，按眼径对齐双眼会挤到鼻子上。详见质量报告 P2。
3. 帽子只能占 y6–23（18 行），比正式帽子略大但仍偏「小帽」。这是身体比例问题（双耳内缘只有 7→3 px 间距），不是本次素材的问题。
