## 三、状态、失败与降级

| 条件 | 展示与恢复 |
|---|---|
| 首次读取中 | 中性加载，不预判running/done；不能把整个旅途等待期做成加载动画 |
| running | 等待布局；不显示发现，也不显示未经证实的实时地点 |
| done | 正常归来布局；内容分别读取，缺失/失败分别提示 |
| timeout | 独立终止降级态，可写“这趟旅途已结束，记录可能不完整”；读取已存内容，不强行零发现或成功归来 |
| failed | 独立旅途错误态，可写“这趟旅途未能完成”；已存内容仍可只读查看，不写成功归来 |
| HTTP读取失败 | 明确“暂时读不到”和允许的读取重试；不当作running、done或空列表，不POST新旅途修复 |
| 缓存/断网 | 明示上次记录/本地内容，不冒充当前状态；缺图有静态回退 |
| 无旅行/无权限 | 区分无记录与不可访问，不泄露他人内容 |

终态停现有轮询，不新增计时机制。已知出行状态与内容读取结果分别处理；没有Message不编归来话，发现读取失败不等于零条。fixture/测试内容明确标识，不抵充真实成功验收。

## 四、发现排序和摘要

基本排序`createdAt ASC, id ASC`。同trip有效`message.mentionsFindId`前置为代表发现；缺失/无效用基本排序首条；按id去重，代表项不再重复，其余维持基本顺序。不随机、不按kind或点赞改变顺序。重复来源交C治理，不以标题相同擅删不同事实。

不足3条如实展示，零条用中性空态，不补造、不复制；超过5条保留真实记录可访问并核上游，不静默丢失。3—5条与真实可点知乎原文仍是完整闭环目标。

展示优先：标题、来源/示例标识、有效原文入口，其次有效摘要，最后记录时间。excerpt为空不留空白；与已显示归来话确实重复才可省，mentions引用本身不等于重复。createdAt按记录时间理解，不包装成精确发生时间。没有合法链接不造按钮。

## 五、尺寸、AI背景与像素规范

**375px是页面宽度，不是整幅图片的宽高比。取消旅途背景强制长边1200要求。** 源图按批准容器比例、像素网格及清晰度定义；朋友圈等其他用途原尺寸不因本条改变。

| 容器参考 | 当前E4显示 | 对应2倍输出示例 |
|---|---|---|
| 过程场景 | 375×365 | 750×730 |
| 归来场景 | 375×260 | 750×520，或同图等比裁切；高度仍需解决上一节验收冲突 |

尺寸随375×667最终布局同步复核。前端等比缩放或安全裁切，不拉伸。检查320、375、平板、桌面的角色脚底、地面、安全区和明暗对比，不只检查顶部可裁15%。两态允许同图裁切，也允许分别出图，不强制每地点两张。

背景是**纯像素风**：统一色板、硬边像素网格；提前生成后按SOP降采样、固定色板量化、最近邻放大并校验。固定风格/构图及平视规则，地点作为受控槽位；随机氛围不能作为实际find来源。不画角色、衣帽、角色阴影、文字、按钮或UI。

背景整图＋独立角色/阴影不是远/中/近分层场景合成；**c11c已删除，不恢复**。逐帧运动用CSS/SVG/精灵代码，不能AI逐帧生成。此轮先交一张背景与一套新角色装配静态样张；旧8—12张/六地点计划不构成现在启动批量生成的授权。
