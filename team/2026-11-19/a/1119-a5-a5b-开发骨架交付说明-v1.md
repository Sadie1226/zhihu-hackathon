# A5/A5b 开发骨架与接入说明

2026-11-19，分支 `a5-a5b-react-1119`，基于 main `cf029b3`。这是可运行的开发阶段实现，**不是正式OAuth、全业务集成或最终视觉验收完成**。请求与本说明分开存放，不记为请求方已交。

## 本次实现

- `/adopt`：显式测试身份、模拟四类资料状态、必填1–6字名字、可跳过/选2–3类兴趣、六倾向、服务端三标签、试验四键装配、事务创建与同收据重试、刷新恢复。模拟算法按手动幅度优先，平分用固定模拟资料排序，未作为真实知乎推断算法定案。
- `/home`：v25静态房间及分层参考角色、内部名牌/四入口/设置、独立可点状态句；档案仅改名并持久化；单一原生dialog宿主、Escape/遮罩关闭、焦点恢复、草稿保留、身份变更清理、错误边界、减少动态偏好。
- `/trip`：复用C4列表与700ms串行轮询，终态停止，卸载取消；空/终态每30秒检查下一趟，页面重新可见时刷新；不创建/开始/结束出行。running不创建发现区，done/timeout/failed预留只读内容。缺少接口时明确未接入，不造假分享。
- 根layout覆盖所有路由组；`wiring.tsx`是唯一业务装配点，`ports.ts`提供B/E模块、邀请、只读归来内容、两态场景接口。四个尚未集成入口禁用，避免跳死页面。
- HTTP A侧只序列化DogView，私有响应no-store/Vary Cookie，同源写校验；不接受客户端owner/session/tags。未改公共types/schema/migrations。

## 本地启动（PowerShell，Node24+）

```powershell
npm.cmd ci --no-audit --no-fund
$env:APP_IDENTITY_PROVIDER='development'
$env:DATABASE_PATH='./data/a5-development-review.sqlite'
npm.cmd run dev -- --hostname 127.0.0.1 --port 3105
```

打开 `http://127.0.0.1:3105/adopt`。不必配置任何密钥，不调用知乎线上接口。开发身份只有非production、显式provider、专用文件名三项同时满足才开放；默认/production只显示真实登录未开放。测试只在独立库进行，不接正式邻居池。修改DATABASE_PATH后重启进程。

## HTTP与维护边界

| 方法/路径 | A侧用途 |
| --- | --- |
| GET `/api/session` | provider/authenticated/DogView |
| POST `/api/auth/development` | 仅开发会话cookie |
| POST `/api/auth/logout` | 清当前cookie；服务端撤销待C |
| POST `/api/adoption/profile` | 当前固定mock状态/版本，不返回原始知乎资料 |
| POST `/api/adoption/personality` | 校验草稿，返回三个标签与指纹 |
| POST `/api/dogs` | 校验当前草稿/装配/指纹/重试标识后保存 |
| GET `/api/dogs/:id` | 当前会话所属DogView |
| PATCH `/api/dogs/:id/name` | 仅接收 `{name}`，只更新name列 |

`lib/adoption/view.ts`为暂行页面DTO，正式公共契约由C定。开发创建收据暂编码于开发专用id并用事务保证单狗，不新增公共表；正式账号需C提供owner、唯一约束、服务端收据与撤销会话。当前logout清cookie后旧cookie仍可重放，**不满足真实账号退出验收**。尚无真实OAuth回调/Token交换/用户资料适配器，12-05单独联调HTTPS/state/uid/过期与授权人隔离。测试狗不迁移。

A维护路由/容器/装配/领养业务；B提供正文与唯一回应；C维护契约、迁移、身份底座与归来只读；D维护社交事实/池隔离；E提供正式视觉与来信/手账。所有模块通过实际导出和接口交付，由A合入；不要多人编辑wiring或另造相同业务能力。
