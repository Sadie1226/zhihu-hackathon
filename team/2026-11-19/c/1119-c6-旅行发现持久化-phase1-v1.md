## 内部写入边界

```ts
const store = createFindStore(db)
const find = store.write(input, serverSessionId)
const finds = store.list(tripId, serverSessionId)
```

input 沿用现有 Find 字段：tripId、kind、title、excerpt、sourceUrl、sourceMode、
authorityLevel、voteUpCount、assetPath，不接收客户端 id/createdAt 或 session_id。
服务端生成稳定 id 和 UTC ISO 时间。测试通过注入 now 固定时间，未修改生产时钟。

scene/moment 另需内部稳定 `sourceKey`，表示生成材料的来源身份；它不是标题、界面参数或数据库列，
不出现在 Find 返回值中。调用方必须对同一材料复用该 key，不能每次重试随机换 key。
zhihu 不接受自定义 sourceKey，使用校验后的来源 URL。

写入在一个同步 `BEGIN IMMEDIATE` 事务中完成：验证 trip 所属 session、running/started_at、
数据和来源、既有行检查、INSERT，最后提交。出错回滚并释放写锁。
调用方不要在已有事务里嵌套调用 write；当前 helper 自己拥有完整事务边界。

仅 running 可写，pending/done/failed/timeout 不可写，已经结束后再次写入也返回 CONFLICT。
历史读取不限 running，结束后的手账仍可读取。缺失/跨 session 为 NOT_FOUND，非法材料为 CONFLICT。

### 稳定去重与冲突

id 为 `find_` + SHA-256(JSON.stringify([版本, tripId, kind, 来源身份]))：

- zhihu：来源身份为规范 HTTPS 知乎问题/回答/文章 URL；移除 query/fragment/尾斜杠，
  zhihu.com 统一 www.zhihu.com，保留完整回答/文章 ID，不转 number。
- scene/moment：来源身份为服务端 sourceKey，kind 参与作用域。
- 同一来源跨 trip 生成不同 ID；两个不同回答保持不同身份。

复用现有主键及 idx_find_trip，无新索引。先按稳定 ID 查找，zhihu 也检查同 trip 内
旧的非稳定 ID 来源行，防止旧数据被重复生成。
冲突时核对 trip、kind、URL、sourceMode 和全部持久字段；相同材料返回原行及原 createdAt，
内容/元数据/图片路径不一致则 CONFLICT，保留原记录。没有 INSERT OR REPLACE 或 UPDATE 历史。
两个独立进程并发写同一 fixture，测试确认只存一行且返回同一 ID。

### 数据与真实性

title 非空，excerpt 为 string/null；等级为 1–4/null，赞数为非负安全整数/null。
assetPath 为本地根相对路径或 null，拒绝外部地址、路径穿越及控制格式。
知乎来源必须是受信任 HTTPS 的问题、回答或文章路径，拒绝脚本 URL、外部域、凭据和错误内容路径。
地址合法只证明链接形状，不证明搜索发生过。

**本阶段 zhihu 写入只接受 sourceMode=fixture。live/cache 一律拒绝。**
没有伪造可验证的 live 来源对象，也没有凭一个知乎 URL 就写 live。
scene/moment 只接受 sourceMode=null；测试材料本身明确标记为 fixture，但不改变这两类的契约空值。
写入不会推断或编造等级、赞数、图片、正文或搜索结果。

## GET 接口

`GET /api/trips/:id/finds`：

- 复用现有 readSessionId，验证匿名 cookie，不接受 query/body 覆盖 session。
- 在同一读取事务中验证归属并查询；查询再次 join dog.session_id。
- 非法 ID、无效/缺失/重复 cookie、跨 session、不存在和未定义 query 均 HTTP 404 / NOT_FOUND。
- 所属 trip 无发现时 HTTP 200 `{ finds: [] }`；有发现时为 camelCase Find[]，含 assetPath。
- 按 created_at、id 升序返回，沿用已有 finish 的字段与排序口径。
- 所有响应 Cache-Control: no-store，Vary: Cookie；数据库故障为脱敏 503 / NETWORK。
- GET 不触发发现生成、出行更新、投递、已读或回应操作。
- 没有公开 POST；实际 Next.js 生产路由验证 POST 返回 405。
