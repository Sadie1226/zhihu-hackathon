## 1. 上传接口形状（A 要的第 1 件）

```
POST /api/uploads/photo
入：multipart/form-data，文件字段名 file
出：{ "url": "/uploads/s_<session前8位>_<随机串>.webp", "bytes": 123456, "mime": "image/webp" }
错：
  413 太大（上限 5MB）
  415 格式不支持（只认 jpg/jpeg/png/webp，看文件头）
  401 无有效会话
```

**我自己定的三件事**：上限沿用 b3 的 **5MB**；**压图**，最长边到 **1600px**（手机原图常 3–8MB，演示网速不可控；代价是画质下降，我接受）；存 `public/uploads/`，**随机文件名不带原文件名**（原文件名会泄漏本地信息，如 `IMG_20261118_我家的猫.jpg`）。

**落位提醒**：`README.md:143,159` 把 `app/api/`、`scripts/` 划给 C，但 `contracts/api.md:6` 又把回应接口标为「b 实现，唯一」。实现前请 A 在归属表划格或 C 点头；若维持现状，代码放 `app/(b)/api/uploads/photo/route.ts` 与 `app/(b)/api/replies/route.ts`，route group 不进 URL，对外路径不变。

## 2. 校验规则表（A 要的第 2 件）

| 检查什么 | 规则 | 不满足时（mustFail） | mustPass |
| --- | --- | --- | --- |
| 大小 | ≤5MB（超限时先压图，压后仍超才拒） | 返回 413，界面就地提示，**已输入文字不丢** | 4.9MB 上传成功 |
| 格式 | **看文件头不看扩展名**，只认 jpg/jpeg/png/webp | `a.exe` 改名 `a.jpg` → 415 | 真 webp 通过 |
| 尺寸 | 最长边 ≤1600px（压图后） | 超出则压缩；压不动 → 415 | 4000px 原图压后通过 |
| 归属 | 必须带有效 session；文件名 `s_<session前8位>_<随机串>` 与当前会话一致 | 无 session → 401；别人空间 → 401/404 | 本人会话成功 |
| 文件名 | 随机串，不含原文件名 | 出现 `IMG_*.jpg` 之类 → 拒 | 随机名入库 |

> 「看文件头不看扩展名」是硬要求：只查扩展名等于没查（`1118-a-给B:122`）。

## 3. `photoUrl` 来源收口（A 要的第 4 件）

`POST /api/replies` 入参仍是 `{ exchangeId?, invitationId?, text?, photoUrl? }`（`api.md` 第 6 节），但 **`photoUrl` 只接受上传接口返回的地址**：

| 塞进来的 `photoUrl` | mustPass / mustFail |
| --- | --- |
| `/uploads/s_<本人session8>_<随机>.webp`（上传接口真实返回） | mustPass：入库 |
| `/assets/photos/6mb.jpg`（声称 6MB 的假地址） | mustFail：拒 |
| `/assets/photos/a.exe` | mustFail：拒 |
| `''`（空串） | mustFail：拒（当作没传图；纯文字路径仍可提交） |
| `javascript:alert(1)` | mustFail：拒 |
| 别人 session 前缀的地址 | mustFail：拒 |

依据：`1118-a-给B:136-150,204`。这四条正是 A 实测「全都能插进去」的四种，必须逐条挡住才算补齐。

## 4. 失败界面四态（A 要的第 3 件，b3 已写一半）

| 状态 | 界面表现 |
| --- | --- |
| 上传中 | 不清空输入框；按钮禁用；显示可取消的进度 |
| 上传失败 | 就地说明「图没传上去」＋上限/格式原因；**已输入文字不丢** |
| 回应提交失败 | 与上传失败**提示语不同**——「回应没发出去」；保留文字与已传图的地址，可重试 |
| 断网 | 图可以先不发，**纯文字也能提交**（P0 第 6 条兜底） |

依据：`1118-a-给B:124-134`；b3 修订稿 `:12-14` 已有「照片失败就地提示…已输入文字不丢；重复提交只产生一条回应」，本表保留并补齐。

## 5. 机检用例表（mustPass / mustFail）

| # | 用例 | mustPass | mustFail |
| --- | --- | --- | --- |
| 1 | 正常上传 | 真 webp、4.9MB 内、本人 session → 200 + 三字段 url/bytes/mime | 返回 200 但缺字段 |

| 7 | photoUrl 收口 | 上传接口返回的地址入库 | 四种假地址任一入库 |
| 8 | 失败分态 | 上传失败与提交失败提示语不同、文字保留 | 两次失败同一句话；文字丢失 |
