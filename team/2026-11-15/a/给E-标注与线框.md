# 给 E · 标注文案与线框（11-16 / 11-17）

> **这份文件怎么用：** 整份贴给你写代码的 AI，前面加一句：
> 「按下面这份文案和线框做页面。**文案是定稿，不要改写措辞**；线框的字段标注按 `contracts/` 走，别自己加字段。」
>
> 这里只有**文案、线框、标注规则**。视觉风格、组件库、资产规范都是你的事，我不进那个层。

---

## 一、四态是硬要求（不是「有空再做」）

每个页面必须能显示四种状态。**只做「正常有数据」是最常见的假完成**，评委会专门去点空的地方。

| 态 | 要求 |
| --- | --- |
| **空** | 有话说，不是一片白。空状态文案见下 |
| **加载** | 有反馈，最长 2 秒，超时也要给结果 |
| **失败** | 说清是什么失败 + 一个重试入口 |
| **降级** | 数据不是现拿的，**界面上必须写出来** |

### 空状态文案（直接抄，不要改）

| 页面 | 文案 |
| --- | --- |
| 来信（还没有东西） | 「还没有谁捎东西来。它出门的时候会看看信箱。」 |
| 来信（有在路上的） | 「有东西在路上，还没到。」 |
| 手账（还没记录） | 「走过的地方会记在这里。」 |
| 朋友圈（还没有动态） | 「它还没发什么。等它觉得值得说的时候。」 |

**四条都不许出现：** 感叹号、催促、「快去」「还没有哦～」。

---

## 二、「示例伙伴」的标注（不变量四，阻断级）

种子狗装成真人养的，是这个产品最容易被戳穿的地方。**四处必须有，一处都不能少：**

| 位置 | 文案 | 样式 |
| --- | --- | --- |
| 来信里，这条记录下方 | 「这位是示例伙伴，由团队预置，不是真人养的」 | 小字，不抢主内容，但不能淡到看不见 |
| 交换记录里，狗名字后面 | 「示例」 | 浅色小标签，紧跟名字 |
| 朋友圈里，这条动态的作者 | 「示例」 | 同上 |
| 手账里回看这段关系 | 「示例」 | 同上 |

**用户给示例伙伴捎话时，当场提示：**
> 「这是一位示例伙伴，可能不会回话。」

**做这条的红线：绝不能出现「对方正在打字」「刚刚活跃」这类暗示有人在另一头的状态。** 一旦出现就是伪造真实用户内容，算阻断缺陷。

## 三、`sourceMode` 的三档文案（不变量四）

数据不是这条请求现拿的，就不能标 `live`。三档在界面上必须能分辨：

| `sourceMode` | 什么时候 | 界面必须写 | 还要求 |
| --- | --- | --- | --- |
| `live` | 本次请求真的打到知乎 | 「刚从知乎看到」 | 原文可点 |
| `cache` | 24 小时内的真结果 | 「几小时前看到的」 | **原文仍然可点** |
| `fixture` | 假数据（含全部种子狗） | 「示例内容」**加醒目样式** | 不能点开假链接 |

**注意 `cache` 的原文链接必须仍然可点。** 缓存的是内容，不是链接 —— 链接失效会让评委当场判定骗人。

## 四、a4 领养页线框（11-17，手机竖屏一屏做完）

**这是陌生人打开产品的第一屏，也是人气奖那一票的入口。不设引导页、不设注册墙。**

```
┌─────────────────────────┐
│                         │
│      （狗站在门口，      │
│       还没名字，在等）    │
│                         │
│  它还没有名字            │
│  ┌───────────────────┐  │
│  │                   │  │  ← 输入框，可不填
│  └───────────────────┘  │
│  [ 让它自己想一个 ]      │  ← 点了换一个候选名
│                         │
│  它平时会去看看这些        │
│  [自然风景] [城市角落]    │  ← 6 个 chips，选 2–3
│  [手作与食物] [人与故事]   │     不选也能继续
│  [动物与植物] [冷知识]    │
│                         │
│  ┌───────────────────┐  │
│  │     就这样吧        │  │  ← 唯一主按钮
│  └───────────────────┘  │
│                         │
│  （不注册、不登录、不绑）  │
└─────────────────────────┘
```

### 字段标注

| 界面元素 | 字段 | 约束 |
| --- | --- | --- |
| 输入框 | `name` | 1–6 字符，**可空**，不通过时就地提示一行，不弹窗打断 |
| 6 个 chips | `interest_categories` | 选 2–3，**可空**（空＝全都要） |
| 主按钮 | 提交 `name + interest_categories` | 返回带 `personality_tags` 和 `assembly` 的狗，跳 `/home` |

**标签由服务端生成，页面上不让人手选标签。** 这是 a 的判定：手选标签就没有「它是谁」的意外感了。

### 四态

| 态 | 具体表现 |
| --- | --- |
| **空** | 不存在 —— 首页直接是领养 |
| **加载** | 点「就这样吧」之后狗在门口等，最长 2 秒，超时也要给结果 |
| **失败** | 保存失败，就地一行字 + 「再试一次」，**名字和选中的 chips 都不能丢** |
| **降级** | 断网时先存本地，如实写「还没保存到线上」 |

## 五、给 e 的视觉形容词（性格标签的第三层）

**标签怎么映射到具体部件，是你定，不是 a 定**（03 规定的第三层）。我给的是形容词，你决定哪个部件配哪个词。

| 维度 | 极 A | 极 B |
| --- | --- | --- |
| 探索范围 | `好奇`：帽子 / 亮色 / 往外走 | `恋家`：围巾 / 暖色 / 停在门口 |
| 对陌生人 | `自来熟`：张嘴笑 / 配饰多一点 | `慢热`：眼神偏开 / 素一点 |
| 说话密度 | `话痨`：配饰多 | `寡言`：简洁，一个亮点就够 |
| 关注对象 | `看物`：干净线条 | `看人`：带书 / 报纸 / 小物 |
| 表达方式 | `直给`：方，直角元素 | `婉转`：圆，弧线元素 |
| 时间感 | `当下`：新东西 | `怀旧`：旧物，褪色 |

**情绪表情四档，和 4.4 对应，必须叠在服装之上**（否则一戴墨镜就看不见情绪）：

| 表情 | 什么时候用 |
| --- | --- |
| `happy` | 日常、归来 |
| `tired` | 走远了、晚上 |
| `hopeful` | 出门前、发出邀请 |
| `waiting` | **朋友的东西到了，在等回应** |

## 六、我唯一会拦你的三件事

①「示例」标注少一处 —— 阻断缺陷。
②`cache` 的数据标成 `live` —— 阻断缺陷。
③空状态出现催促词或感叹号 —— 违反不变量三。

其余视觉、布局、动效、组件库全是你定。**出问题我只会说「这条不行」，不会替你改。**
