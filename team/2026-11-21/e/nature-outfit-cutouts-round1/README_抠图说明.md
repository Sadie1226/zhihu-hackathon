# 刘看山第一轮服装抠图

- `01_frog_forest_explorer.png`：森林探索蛙装（蛙形头套、短披肩/外套、口袋、斜挎装饰）。
- `02_sky_blue_hoodie.png`：云朵蓝色连帽装（帽子、连帽上衣、抽绳、云朵标、斜挎小包与肩带）。
- `03_winter_postal.png`：冬日邮差装（针织帽、围巾、短外套、邮差包与肩带）。
- `00_cutout_preview.png`：透明底预览图；棋盘格仅用于显示透明区域。

## 处理说明
三张素材均为 RGBA PNG，服装外部区域为透明；脸部开口保留透明。服装边缘和深色轮廓保留，尽量不把角色手脚与尾巴纳入服装。

## 使用边界
这是从完整穿搭图提取的首轮视觉抠图，不是原始分层工程文件。衣服与角色身体、配件在原图中存在遮挡，正式接入前仍需叠加到中性底身上，检查脸部开口、肩线、衣摆、手臂、尾巴和脚部是否遮挡，并微调少量边缘。
