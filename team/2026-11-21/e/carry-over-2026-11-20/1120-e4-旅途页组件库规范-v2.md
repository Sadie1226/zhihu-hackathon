## 2. C1 · `.trip-scene`

**用途：** 承载纯像素背景，并为 C2 提供定位坐标系。

建议结构：

``` html
<figure class="trip-scene" data-state="running">
  <img class="scene-art" src="..." alt="">
  <!-- C2 新角色和独立阴影 -->
</figure>
```

规则： - 容器宽度必须显式 `width:100%`，防止仅用
`aspect-ratio + min-height` 时宽度被高度反推。 -
背景等比显示或安全裁切，不拉伸。 -
`image-rendering: pixelated`；硬边像素不柔化。 -
无边框、无圆角、无装饰阴影。 - 背景不得烘焙角色、角色阴影、文字或 UI。 -
375×667 归来态需要为首屏留足高度；实际容器高度按 v2 预算测量，不沿用旧
260px 直接宣布通过。

## 3. C2 · `.trip-actor`

**用途：** 将新角色作为独立图层叠加在场景上。

建议结构：

``` html
<div class="trip-actor" role="img" aria-label="刘看山">
  <img class="actor-shadow" src="..." alt="">
  <div class="actor-assembly">
    <!-- 新底身、衣服、配饰等独立图层 -->
  </div>
</div>
```

规则： - 只使用经批准的新 reference + pixel 底身和装配件。 - 旧 96×96 与
100×116 角色均停用。 -
角色画布尺寸、锚点、缩放倍数必须从新素材实测后确定；不得先验写死旧
192/288px 容器或 88% 脚底锚点。 -
角色、衣服、帽子、眼镜等可独立叠加；部件透明区域必须真实透明。 -
阴影独立于背景，可随角色位置变化；不得烘焙进 Scene。 -
正式层序由新素材装配样张验证后记录，不得沿用旧装配契约擅自新增字段。 -
两态使用同一角色身份与比例；表情变化若需独立层，应由 A/C 确认现有 face
契约后再接入。

## 4. C3 · `.trip-status`

-   主状态简短、清楚，最多两行。
-   辅助氛围句可选；不得编造实时位置、进度、距离或确定归来时间。
-   文字是真实 DOM，不得烘焙进场景。
-   `read-error` 时不得显示"它还在路上"等与错误矛盾的过程态文案。

## 5. C4 · `.trip-return`

-   仅使用实际 `Message.text` 原文，不改写、不润色。
-   没有 Message 时不编造角色原话；可不渲染该区。
-   来源与示例标识是真实 DOM 元素。
-   归来话与发现摘要是否重复，按视觉规范 v2 的摘要规则处理。

## 6. C5 · `.trip-finds`

-   只显示真实读取到的发现。
-   排序：基础 `createdAt ASC, id ASC`；有效 `mentionsFindId`
    对应项前置；按 id 去重。
-   不足 3 条如实展示，不补造、不复制。
-   原文入口必须使用真实有效链接；无链接不造按钮。
-   来源、示例、缓存状态清楚标记。
-   发现读取失败时显示独立 read-error，不当成空列表。
-   零发现是业务空态，不得与读取失败混淆。

## 7. C6 · `.back-home`

-   两态始终可见。
-   页面只保留一个明确回小屋入口。
-   触达区至少 44×44px。
-   不新增到应用主导航作为第五项。

## 8. C7 · `.state-panel`

状态面板覆盖首次读取、读取失败、缓存提示等，不承担业务成功语义。

  情况         面板/提示              操作
  ------------ ---------------------- ------------------------
  首次读取     中性 loading           不显示伪进度
  read-error   "暂时读不到这段旅途"   只重读内容；回小屋
  timeout      独立终止说明           可读已存内容
  failed       独立错误说明           已存内容可只读
  cached       顶部"上次记录"提示     保留原内容，不冒充最新

重试不得 POST 新旅途。`timeout` / `failed` 不得映射为成功归来态。

## 10. 验收边界

-   本文只定义组件规格，不代表 React 组件已创建或接入。
-   A 负责页面、状态接线、统一 Dog 入口、真实数据与路由。
-   E 不改 `contracts/`、正式 manifest、A 的 `wiring.tsx` 或生产素材。
-   组件验收必须与 375×667、320×568、1440×900
    实际样张、角色装配样张和可复现测量一起完成。
