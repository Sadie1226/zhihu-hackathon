## 自动归来调用链

```text
createTripReturn(db, { generationTimeoutMs, generate, writeMessageInTransaction })
  .owner({ request, dogId, tripId }) / .seed({ dogId, tripId, intentId })
    → C4 短事务验证 scope、Trip、确定 Message ID 和 C6 回执
    → 如已确认，校验并回放，或按当前可见性隐藏
    → 如可执行，短事务结束后调用受控生成
    → C4 BEGIN IMMEDIATE
      → 重新鉴权，优先认定并回读赢家
      → 核 running、回执完整性、排序后的可见材料及屏蔽规则
      → C4 原状态转换 done/endedAt
      → B5 事务内验证草稿并 INSERT 指定主键
      → C 以主键读回，核同 Trip、时间、可见引用和屏蔽文本
      → COMMIT 后回传实际 Message
```

- 自动主键为 `msg_auto_return_v1_` 加 SHA-256，摘要绑定 owner/seed 区分、owner ID、dogId、tripId、发现 intent。主人沿用 `ownerDiscoveryIntent(tripId)`，种子核原 intent 的确定 Trip ID。主键由服务端生成，命名与普通随机 `msg_<UUID>` 不同，需为自动入口保留。精确查询后核 Trip、done、同一结束与 Message 创建时间、合法引用及回执时序。非预期主键占用失败；普通历史消息可保留多条，且不参与自动首次确认。保留 v8，无迁移及通用唯一约束。
- 模型只接当前可见 Find 与 owner/seed 类型。提交重新比对输入材料（含顺序）、回执完成时间及当前屏蔽。主人复核原有效会话及 token hash 和目标归属；样本只走无 owner 样本内部权限，使用调用方显式提供的受控生成器。无可见材料返回 `not-ready`；旧 hold 停止；损坏回执报错。过程不补 Find、不调用 C5/C9。
- 在等待时竞争者完成则回放赢家。授权撤销或依据变化拒绝提交。外部另行结束的 Trip 返回终态，不假报自动成功。生成异常走既有 failed，超时走 timeout，二者均无 Message。超时为调用方显式设置的真实计时，向生成器传 AbortSignal，迟到结果不能再次提交。数据或写入错误回滚并保留可按原 Trip 重试。
- 自动回放保守处理当前隐私。任一回执成员被过滤，或当前屏蔽命中存储正文时，返回 `confirmed-hidden`，不返回正文、不重新生成。现有主键无法保存生成当时输入的子集，因此即使仅有历史上未纳入生成的成员被过滤，也可能隐藏。由 A/B 确认可见性策略后再接既有 Message GET，当前 GET 按历史最新行读取，不能直接作为自动确认投影。

## 给 B 的接缝

`generate({scope,finds}, signal) → Promise<unknown>` 在事务外，用传入的合法材料生成。若未来需要追加角色等输入，先一并定义事务内可复核依据。 `writeMessageInTransaction(db, {id,tripId,createdAt,allowedFindIds}, draft) → undefined` 同步运行于 C4 已开启的写事务。B 复用自己的形状、文本、引用校验，以指定 ID 普通 INSERT；不要另开事务、生成随机 ID、覆盖历史或调用模型。C 读回实际行并验证归属与可见来源。若 B5 要单独处理内容不可接受的失败路径，按实际业务错误接线。本轮不存在生产写入适配器。

## B6 与后续
