## 一、命名规则

```
{场景}-{对象}-{状态}-{宽}w.{格式}
```

| 段 | 说明 | 例子 |
| --- | --- | --- |
| 场景 | 所属场景或层级 | `layer0` `layer1` `home` `trip` `ui` |
| 对象 | 具体是什么 | `base-tpl-a` `cloth-hoodie` `btn-primary` |
| 状态 | 状态变体（见下方说明） | `happy` `red` `default` `disabled` |
| 宽 | 宽度像素值 | `1600` `256` `64` |
| 格式 | 文件格式 | `webp` `svg` `png` |

**完整例子：** `layer2-cloth-hoodie-red-256w.png`

## 二、四种状态变体说明

**注意：这里说的是资产本身的状态变体，不是页面的四态（空/加载/失败/降级）。**

### 2.1 狗狗角色状态变体

| 状态 | 说明 | 对应场景 |
| --- | --- | --- |
| `happy` | 日常、归来 | 小屋、旅途归来 |
| `tired` | 走远了、晚上 | 夜晚小屋、timeout 归来 |
| `hopeful` | 出门前、发出邀请 | 出门状态、邀请面板 |
| `waiting` | 朋友的东西到了，在等回应 | 信箱有未读、邀请 waiting |

### 2.2 UI 组件状态变体

| 状态 | 说明 |
| --- | --- |
| `default` | 默认状态 |
| `hover` | 悬停（仅桌面端） |
| `active` | 按下 / 选中 |
| `disabled` | 不可用 |

### 2.3 场景素材状态变体

| 状态 | 说明 |
| --- | --- |
| `day` | 白天 |
| `dusk` | 黄昏 |
| `night` | 夜晚 |
| `rain` | 雨天（可选） |

| 层 | 尺寸 | 说明 |
| --- | --- | --- |
| 主画面 | 800 × 800px | 五层合成的最终渲染区域 |
