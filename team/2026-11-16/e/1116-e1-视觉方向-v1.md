## 选择方式

三套方案各有优劣。请每人看完后回答一个问题：

**「打开这个产品，你希望第一眼是什么感觉？」**

- A：像翻开一本旧绘本
- B：像清晨的第一缕雾
- C：像窗台上刚醒来

投票截止后，e 按获选方向出三张关键稿（小屋、旅途、朋友来信）。

## 方案 A · 暖纸手绘

### 关键词

温暖、手作、绘本感、有笔触

### 色彩

| 用途 | 色值 | 说明 |
| --- | --- | --- |
| 主色 | `#BA7517` | 琥珀暖棕 |
| 辅助色 1 | `#854F0B` | 深棕，用于标题和强调 |
| 辅助色 2 | `#EF9F27` | 亮琥珀，用于点缀和状态 |
| 背景色 | `#F1EFE8` | 米黄纸 |
| 卡片底 | `#FFFFFF` | 白底 |
| 卡片边框 | `#D3D1C7` | 0.5px 细边框 |
| 圆角 | 12px | |

### 狗狗角色

手绘线条加水彩平涂，笔触可见。换装部件用同一种手绘笔法保持一致性。表情通过眼睛和嘴巴的线条变化表达（4 档：happy / tired / hopeful / waiting）。

### 场景与插画

手绘风景插画，像绘本内页。场景素材用层叠的前中远景，每层都是手绘风格的色块加线条。

### 字体

- 标题：衬线体（思源宋体）
- 正文：无衬线（系统默认）
- 狗狗的一句话分享：手写体

### 信息层级

靠字号和颜色深浅区分。不用阴影和渐变。

### 与产品定位匹配度

| 维度 | 评分 | 说明 |
| --- | --- | --- |
| 治愈 | ★★★★★ | 手作温度天然贴合「一只狗自己过日子」 |
| 低压力 | ★★★★☆ | 暖色调降低紧张感 |
| 自主感 | ★★★☆☆ | 绘本风格偏叙事，自主生活感稍弱 |

### 优点

- 最贴合「治愈」定位
- 有手作温度，情绪表达强
- 第一眼辨识度高

### 缺点

- 手绘资产制作量大（40 个换装部件 + 30 张场景）
- 风格一致性维护难
- 可能偏「幼稚」，不够现代

### 第一感觉

像翻开一本旧绘本。

## 方案 B · 雾色极简

### 关键词

干净、安静、克制、现代

### 色彩

| 用途 | 色值 | 说明 |
| --- | --- | --- |
| 主色 | `#534AB7` | 雾紫 |
| 辅助色 1 | `#7F77DD` | 淡紫，用于次要元素 |
| 辅助色 2 | `#185FA5` | 石板蓝，用于链接和强调 |
| 背景色 | `#F5F5F8` | 冷白 |
| 卡片底 | `#FFFFFF` | 白底 |
| 卡片边框 | `#E4E4E8` | 0.5px 极细边 |
| 圆角 | 8px | |

### 狗狗角色

几何扁平矢量，边缘利落。换装部件用统一矢量风格，部件之间靠形状和颜色区分，不靠纹理。表情用最简几何形（圆点眼睛、弧线嘴巴）。

### 场景与插画

色块拼贴，像杂志排版。场景素材用大面积纯色块加少量线条点缀，层次靠颜色明度区分。

### 字体

全无衬线，系统字体栈。两个字重：400 regular / 500 medium。

### 信息层级

靠字号、字重和间距。极致克制，不装饰。

### 与产品定位匹配度

| 维度 | 评分 | 说明 |
| --- | --- | --- |
| 治愈 | ★★★☆☆ | 极简风格偏冷，治愈感需要靠文案补 |
| 低压力 | ★★★★★ | 极简天然不催促，最安静 |
| 自主感 | ★★★★☆ | 现代感强，像「它有自己的生活」 |

### 优点

- 最干净最现代
- 信息层级清晰
- 开发效率最高（矢量部件制作快，CSS 实现简单）

### 缺点

- 可能偏冷
- 治愈感不足，需要文案和交互节奏补
- 个性弱，辨识度依赖交互而非视觉

### 第一感觉

像清晨的第一缕雾。

## 方案 C · 晨光柔和

### 关键词

柔和、亲密、温润、不冷不热

### 色彩

| 用途 | 色值 | 说明 |
| --- | --- | --- |
| 主色 | `#0F6E56` | 鼠尾草绿 |
| 辅助色 1 | `#1D9E75` | 翠绿，用于点缀 |
| 辅助色 2 | `#FAC775` | 暖琥珀，用于温暖感 |
| 背景色 | `#FBFAF7` | 暖白 |
| 卡片底 | `#FFFFFF` | 白底 |
| 卡片边框 | 无 | 靠间距区分 |
| 圆角 | 16px | |

### 狗狗角色

柔和渐变球体风格，边缘朦胧但不模糊。换装部件用同一种柔和方法，颜色过渡平滑。表情通过眼睛形状和身体姿态表达，比几何更柔和但比手绘更规整。

### 场景与插画

柔焦摄影感，像清晨窗景。场景素材用柔和的色块层叠，有轻微的明暗过渡但不做复杂渐变。

### 字体

无衬线圆角体（Nunito / 思源黑体）。两个字重：400 / 500。

### 信息层级

靠字号和间距。标题略大但不夸张。

### 与产品定位匹配度

| 维度 | 评分 | 说明 |
| --- | --- | --- |
| 治愈 | ★★★★☆ | 温暖但不老气，柔和天然治愈 |
| 低压力 | ★★★★☆ | 不冷不热，长时间使用不疲劳 |
| 自主感 | ★★★★☆ | 有现代感也有温度 |

### 优点

- 温暖且不老气
- 昼夜皆宜
- 情绪与功能兼顾

### 缺点

- 风格界定模糊
- 需精确调色，否则容易两头不靠
- 不够手绘的个性，也不够极简的干净

### 第一感觉

像窗台上刚醒来。
