# 合并记录

> **每次合并加一行。** 只有 a 写。
> 它回答的问题是 tag 回答不了的：**那一刻你验了什么、留了什么尾巴、动了谁的代码。**
>
> 想知道「代码在 v3 长什么样」是 tag 的事，不用写在这里。

## 格式

```
日期 · tag · 合了谁的哪些任务 · 验了什么 · 留了什么尾巴
改了什么：动了谁的文件、改了哪一处、为什么（没动别人就删掉这行）
```

**「改了什么」这一行不能省** —— 他靠这一行知道自己要重新 pull 什么。不写，他明天还在旧代码上接着写。
